# Authoring workspace

Create or open a local project from the welcome screen to enter the authoring
workspace. The separate **Explore workspace** demo has been removed.

The project workspace includes the book outline, chapter editor, save state,
autosave, manuscript Find/Replace and startup crash recovery. See
[manuscript search](manuscript-search.md) for search and replacement behaviour.

**Book preview** renders the saved manuscript through the shared semantic pipeline,
after flushing pending edits. **Book design** selects a persisted Community preset;
the preview dialog can switch the same presets without changing manuscript text.
See [book rendering](book-rendering.md) and [book themes](book-themes.md).
Device-specific reflowable preview and publishing exports remain future work.
Other unimplemented controls remain marked as unavailable or mock features.
